# LED Matrix Moving Display (Digital Logic Project)

## Overview
Design and simulation of a moving LED matrix display in NI Multisim using shift registers and multiplexers.

## Capabilities
- Display predefined patterns (character/number/shape)
- Shift left/right (direction control)
- Parallel load and shift
- Clear / reset control
- Modular design (phased implementation)

- `second phase.ms14` — Phase 2 implementation
