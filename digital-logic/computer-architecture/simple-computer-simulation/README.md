# Simple Computer Architecture (Multisim)

## Overview
Design and simulation of a basic computer architecture with a hardwired control unit.

## Implemented Instructions
- LDA
- ISZ
- ADD
- HLT

## Architecture Components
- Program Counter (PC)
- Address Register (AR)
- Data Register (DR)
- Accumulator (AC)
- Instruction Register (IR)
- Control Unit
- Sequence Counter
- E flip-flop

## Control Logic
- Micro-operation based design
- Load / Increment / Clear signals
- RAM Read / Write control
- Automatic Fetch–Decode–Execute cycle

## Files Included
- `Simple Computer.ms14` → Multisim circuit
- `Control Unit.pdf` → Control signal design and micro-operations
