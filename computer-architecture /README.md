# Computer Architecture (Multisim Projects)

This folder contains computer architecture mini-projects designed and simulated in **NI Multisim**, focusing on register-transfer level (RTL) concepts and hardwired control logic.

---

## Projects

### 1) Simple Computer Simulation
A basic computer architecture with a hardwired control unit and an automatic fetch–decode–execute cycle.

**Key elements**
- Registers: PC, AR, DR, AC, IR, TR
- Sequence counter and instruction decoding
- Implemented instructions: **LDA, ISZ, ADD, HLT**
- Integrated system-level architecture diagram included

📁 Folder: `simple-computer-simulation/`

---

### 2) Bus and ALU
A shared 6-bit system bus integrated with an **Accumulator (AC)** and a custom **ALU**.

**Key elements**
- Multiplexer-based shared bus routing
- Register operations: **Load / Clear / Increment**
- ALU operations: **ADD, SUB, AND, NOT**
- Separate bus and ALU diagrams included

📁 Folder: `bus-and-alu/`

---

## How to Use
Open the `.ms14` files in NI Multisim.
Each project folder includes:
- `README.md` for documentation
- `.ms14` simulation file
- Diagrams (PNG) and/or report (PDF)
