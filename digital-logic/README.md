# Digital Logic (Multisim Projects)

This folder contains digital logic mini-projects designed and simulated in **NI Multisim**, focusing on **combinational/sequential circuit design**, modular implementation, and step-by-step verification.

## Projects

### 1) LED Matrix Moving Display
A moving LED matrix display implemented using sequential logic blocks to store patterns and shift them across the matrix with direction control.

**Key elements**
- Predefined pattern representation (character/number/shape)
- Shift left/right (direction control)
- Parallel load and shift behavior
- Clear / reset control
- Modular development in phases (incremental build-up)

📁 **Folder:** `led-matrix-display/`

---

### 2) 7-Segment Display (Hexadecimal)
A 7-segment display decoder that supports **decimal digits and hexadecimal symbols (A–F)** using combinational logic equations and gate-level implementation.

**Key elements**
- 7-segment decoding logic for **0–9 and A–F**
- Gate-level implementation (AND/OR/NOT network)
- Segment-level logic validation using truth table / derived formulas
- Multisim schematic + supporting formulas/report included

📁 **Folder:** `7-segment-display/`

## How to Use
Open the `.ms14` files in **NI Multisim**. Each project folder typically includes:
- `README.md` (documentation)
- `.ms14` simulation file
- Diagrams (`.PNG`) and/or report (`.PDF`)

## Tools
- **NI Multisim** (circuit capture and simulation)
